# ScopeSentry-R Inventor and Faculty Review Checklist

This checklist is intentionally blank for human completion. It is not evidence of approval, inventorship, independent validation, or patentability.

## Technical accuracy

- [ ] The canonical disclosure matches the implemented modules and schemas.
- [ ] Synthetic providers are not described as commercial-provider integrations.
- [ ] Runtime decisions are identified as simulator decisions over supplied observations.
- [ ] Process-local contract storage is stated.
- [ ] Observed flows are distinguished from authorized flows.
- [ ] Evidence is described as tamper-evident, not tamper-proof.
- [ ] Bounded synthesis is limited to the configured finite catalogue and risk model.
- [ ] Remediation is described as a recommendation rather than automatic revocation.
- [ ] Existing and future embodiments are clearly separated.

## Experimental accuracy

- [ ] V1 and V2 terminology is consistent with the glossary.
- [ ] Corpus counts and hashes match the frozen reports.
- [ ] Confusion-matrix values match report JSON.
- [ ] Ground truth is labelled author-defined.
- [ ] Timing measurements are described as platform-specific local observations.
- [ ] The static baseline is not presented as representative of all prior systems.
- [ ] No result is described as universal security or formal verification.

## Traceability

- [ ] Each candidate element has source-module and symbol support.
- [ ] Exact automated tests resolve.
- [ ] Scenario identifiers resolve where claimed.
- [ ] Evaluation case/category and metric paths resolve.
- [ ] Evidence event types resolve.
- [ ] Qualifications and limitations are sufficient.

## Inventorship and disclosure history

- [ ] Contributors and their technical contributions have been identified separately.
- [ ] Public disclosures, demonstrations, publications, repositories, or presentations have been listed.
- [ ] Relevant employment, sponsorship, assignment, and institutional-policy questions have been referred for appropriate review.
- [ ] Third-party code and licences have been reviewed through the institution’s normal process.
